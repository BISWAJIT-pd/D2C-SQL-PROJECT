# D2C Fashion Brand Analytics

## Project Overview

This project analyzes customer behavior for a Direct-to-Consumer (D2C) fashion brand operating across the United States. The goal is to transform raw customer transaction data into actionable business insights related to customer loyalty, retention, discount dependency, product preferences, and geographic performance.

## Business Problem

The company has customer data but lacks a structured understanding of:

* Customer retention and loyalty
* Discount and promo effectiveness
* High-value customer segments
* Regional growth opportunities
* Product category preferences

## Objectives

* Segment customers based on purchasing behavior
* Analyze customer retention indicators
* Measure promo and discount dependency
* Identify high-value customer profiles
* Discover regional opportunities
* Build interactive business dashboards

## Tools Used

* SQL (MySQL)
* Python (Pandas, NumPy, Matplotlib,Seaborn)
* Power BI

## Key Insights

* Customer segmentation by value tier
* Promo dependency analysis
* Category-wise performance analysis
* Geographic customer distribution
* Customer satisfaction analysis
